# SDRCloud for Claude

Ask about your SDRCloud account: what is waiting, campaign results, conversions, why a lead or campaign stopped, job status and credits; and make HVO pages and personalised videos.

This plugin connects Claude to the SDRCloud MCP server at https://app.sdrcloud.ai/mcp and adds the `sdrcloud` skill, which tells Claude which SDRCloud tool answers which question and how to present the answer.

## Install in Claude Code

```bash
claude plugin marketplace add SDRCloud-ai/sdrcloud-mcp
claude plugin install sdrcloud@sdrcloud
```

Then run `/mcp`, choose `sdrcloud` and sign in with your SDRCloud account.

## Install on claude.ai or Claude Desktop

Go to Customize > Plugins > Add, and either upload the plugin's zip or add the marketplace's repository. Then open the plugin's Connectors tab, connect `sdrcloud` and sign in with your SDRCloud account. The skill needs code execution turned on (Settings > Capabilities); without it the tools still work, but the skill does not load.

## What it can do

Your SDRCloud admin must have turned on AI client access for the account. The tools read the account and make or change page and video templates, as drafts until you finish them. Making a real page or test video costs credits, and Claude asks you first. They cannot pause, send, approve or buy credits, and they never send anything to a prospect themselves. SDRCloud receives the tool calls Claude makes and their inputs, not your conversation.
