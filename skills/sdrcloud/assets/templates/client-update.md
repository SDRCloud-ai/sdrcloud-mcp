# Weekly client update template

Written to be forwarded to the admin's own client. Fill from `report_campaign_performance` and `report_conversions` for the same campaign and period. No console links, no SDRCloud system labels, no prospect-written text (meeting titles, reply quotes).

```
**{Campaign}: week of {dates}**

{One-sentence headline: the most important result and its direction vs the week before.}

| | This week | Week before |
| -- | -- | -- |
| Emails sent | {n} | {n} |
| Replies | {n} ({rate}) | {n} ({rate}) |
| Meetings booked | {n} | {n} |

**Conversions:** {lead, company} - {meeting booked / link clicked / reply}, {day}.
**Next week:** {one line on what happens next, from the campaign's state}.
```
