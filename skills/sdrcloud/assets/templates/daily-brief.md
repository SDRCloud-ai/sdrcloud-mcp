# Daily brief template

Fill from `account_overview` and `inbox_list` (replies queue); add `status_get` with no job named when the admin asks about failures. Drop any section with nothing in it.

```
**{N} things need you today.**   (or: **Nothing needs you today.** + one line on how things are going)

**Fix** (stops sending until someone acts)
1. {what is broken} - {what it stops}. {console link}

**Reply and review**
- {n} replies waiting for an answer, oldest {age}. {link}
- {n} drafts held for approval. {link}

**Since yesterday**
- {new replies, conversions, failed jobs, as the tools report them}

Next: {one offer that follows from the top item}
```
