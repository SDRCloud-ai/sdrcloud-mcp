# What changed template

For "what changed", "since last week", "how are we trending". Fill from `report_campaign_performance` with the comparison on, plus `account_overview` for anything newly broken.

```
**{Overall direction in one sentence, with the main number.}**

**Up** ▲
- {metric}: {before} → {now} ({diff})

**Down** ▼
- {metric}: {before} → {now} ({diff})

**New since then**
- {campaign paused, mailbox disconnected, job failed, as the tools report them}

Next: {one offer, such as a closer look at the biggest drop}
```
